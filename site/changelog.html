Changelog

Released versions of framekeep-mcp, the adapter on npm

The Windows app is not released yet; when it is, its versions appear here too. Dates are the publish times recorded by the npm registry.

0.2.020 August 2026
  • New: output_mode. video_frames can return frame paths instead of pixels — and refuses to for any recording with a hidden frame, because a path sits one folder away from the original nobody hid.
  • Setup instructions corrected. The published page had been giving Codex users a command that does not run; it now reads --global --client codex --yes.
  • The requirement on Node.js 20 or newer is stated up front, which nothing said before.
0.1.018 August 2026
  • First working release. init writes the client config; video_map and video_frames serve a recording once it has been approved.
  • The config it writes points at an absolute path rather than at npx, so clients that cannot spawn npx on Windows still start the server.
  • Licensed BUSL-1.1.
0.0.118 August 2026

A name placeholder — two files, no code. Listed only so the gap in the version history is not a mystery.
